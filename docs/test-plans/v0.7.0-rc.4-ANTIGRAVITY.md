# v0.7.0-rc.4 正式验收计划

这是待执行计划，不是测试报告。以拟发布的精确 commit 安装 wheel，并记录实际结果。

- 核对 distribution、模块、CLI 和 Codex command 指向同一环境；检查 45 个 Tool、Resource、Prompt 和全部离线/协议检查。
- 实际验证国内查料、库存、数量阶梯价、MOQ/倍数和刷新；上游 403/429 独立报告，不绕过访问控制。

- 缺少可选转换器时结构化报告；未实现的平台不能列为已联通，贸泽/华秋/得捷不纳入本版已实现能力。
