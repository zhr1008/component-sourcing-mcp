# Component Sourcing MCP v0.8.0-rc.6

使用 `$component-sourcing` 明确要求「一键生成 AD 库」或「下载封装」，即可按国内立创 C 号下载原始 EDA 资产、生成 Altium 库并离线核验。普通选型和查型号继续使用原来的查询入口。

- 以 `完整型号_C号` 命名 SchLib、PcbLib 和 STEP。检查符号引用的是改名后的 PcbLib，并从保存的库读回实际嵌入的 STEP。
- 核验报告分别记录引脚与焊盘、阻焊与锡膏、机械层、3D 朝向和证据状态。符号引脚默认 Passive 的差异仅作提示。提供已保存的 PcbDoc 时可盘点其层叠和规则，缺证据仍待核实。
- 本版有 53 个 MCP 工具。既有 `szlcsc_*` 工具及命令入口继续兼容。生成与离线核验使用独立解析器和转换器。

ZIP 包含源码及 Skill，wheel 安装 Python MCP 服务。 [接入及核验说明](https://github.com/zhr1008/component-sourcing-mcp/blob/v0.8.0-rc.6/docs/altium-offline.md)
