# AD Comment、Description 与选型表

按本项目与用户适用要求交付。需要推荐的每个准确型号应给出可复制的 Comment 和中文 Description。器件优选仍取决于实际工况和可用证据。

## 核对来源

- 国内立创以准确 C 号对应的商品页为准。核对品牌、完整订购 MPN、封装、阻值/容值、额定参数、精度、介质等相应字段。保持原括号、大小写、标点、数值和单位，例如 `FH(风华)`、`100mW` 和 `0402`。应将工具生成的字段视为候选。缺项写待核实。只在已约定的 AD Comment 简写和电容微法场景转换格式。
- 同批次、相同 C 号和相同来源版本可复用已核对字段。记录所用商品页链接及原厂出处。若与原厂资料有差异，保留来源差异，按原厂资料判断电气用途与库适配。额定、典型或最大值按实际测试条件区分，后缀和分档保留。
- 阻容优先风华是适用的用户/项目选料偏好时的排序依据。若无法满足条件，继续核对可靠国内品牌。

## 字段格式

- 普通器件的 Comment 用完整订购型号。Description 用半角 `/` 分隔，依次填写 `名称/规格/完整型号/重要参数/封装/渠道料号/品牌`。渠道编号与型号分列。
- 电阻 Comment 无倍率前缀时保留 `Ω`，例如 `100Ω`。有倍率只写数值与 `m`、`K`、`M`，例如 `2m`、`4.7K`、`1M`。Description 保留来源所用单位，通用描述使用阻值、额定参数、精度、等级和封装等已确认字段。
- 电容 Comment 为 `容值/耐压`，例如 `1uF/50V`。Comment、Description 和 BOM 中的微法写 `uF`。通用 Description 为 `名称/容值/耐压/精度/等级/封装`，名称按实际器件类型。介质和工业/车规资格分别核实。
- 电感 Comment 用电感量，通用描述按已确认的相关规格填写。阻容感的型号列用上述规格，具体描述中保留原厂完整型号。其余器件在混合表的通用描述格留空。

## 选型表

每料一行，列序为位号（有则填）、型号（Comment）、料号、用途、封装、通用描述（仅阻容感）、具体描述、商品页链接。全表没有阻容感时省略通用描述列。位号和用途独立填写，位号以原图或源 BOM 为准，备选行保留其适用条件。商品页链接单独指向精确料号。文件用 [固定导出程序](ad-selection-export.md) 生成并按同一份已核对数据读回。
