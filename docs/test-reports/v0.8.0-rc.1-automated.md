# v0.8.0-rc.1 automated validation

Scope: multi-supplier adapter implementation and retained domestic/CAD contracts.
Date: 2026-10-29. This report describes automated evidence; it is not a stable
release or manual manufacturing acceptance report.

- Unit and mock integration suite: 296 tests, including supplier request contracts,
  credentials isolation/redaction, OAuth renewal (including a repeated token),
  pagination, malformed responses, partial failures, MOQ/multiples, packaging stock,
  original currencies, electrical constraints and retained legacy behavior.
- MCP process validation: 49 tools, 2 Resources and 2 Prompts; stdio, HTTP and SSE,
  current/legacy negotiation, structured errors, EOF and HTTP origin/host checks.
- Static validation: Ruff fatal-error rules and Git whitespace checks.

Mouser and DigiKey requests are mocked against verified official contracts.
Authenticated live calls require each user's approved credentials and are not
claimed here. Huaqiu remains an application/documentation channel with an explicit
unsupported response until an authorized API contract is available.

Reproduce with a Python 3.12 development environment:

```console
python -m pip install -e ".[dev,altium]"
python -m pytest -q
python -X utf8 scripts/verify_mcp.py --all-transports --output protocol.json
python -X utf8 scripts/check_publication_privacy.py
```

Use a separate clean Python 3.11 environment with `.[dev]` to check the core-only
installation. Public CI runs both environments. Optional Altium dependency
advisories and manual Antigravity/Altium acceptance remain documented separately.
