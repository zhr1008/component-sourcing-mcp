# Component Sourcing MCP v0.8.0-rc.1

Multi-supplier sourcing adds four tools: `component_providers`, `component_search`,
`component_get` and `component_offers`. Supplier-neutral models keep manufacturer,
MPN, package, packaging, inventory pools, original currencies and quantity pricing
separate. Existing 45 domestic/CAD tools remain compatible.

Official Mouser Search API and DigiKey Product Information V4 clients support
per-user credentials, cleaned responses, short caches, bounded read retries and
persistent request budgets. DigiKey two-legged OAuth tokens stay in memory and
renew on expiry. Private credentials never belong in public examples or reports.

Use [the supplier setup guide](https://github.com/zhr1008/component-sourcing-mcp/blob/v0.8.0-rc.1/docs/supplier-setup.md) for application channels and
the blank `suppliers.example.json` template. Huaqiu currently provides its official
application channel and `UNSUPPORTED_PROVIDER` pending a verified adapter contract.
Mouser/DigiKey official-contract mocks are included; authenticated live validation
requires approved credentials and is not claimed for the maintainer environment.

This remains a pre-release. Optional Altium dependency advisories and the outstanding
manual manufacturing acceptance are described in the repository's existing security
and validation documents.
