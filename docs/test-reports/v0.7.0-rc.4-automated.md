The publication audit identified vulnerable transitive pins in the Altium
dependency. Altium has been moved to an explicit optional extra, and pip was
updated to 26.2.2. The full Altium environment is not dependency-security clean;
see [dependency-security.md](../dependency-security.md). Sourcing core validation
uses a separate environment without Altium/Pillow/lxml, and public CI also tests
that default installation on the minimum supported Python 3.11.

The broader private scanner flagged two reviewed non-secrets: an environment
variable used in an Authorization header and a deliberately fabricated credential
URL that a regression test rejects. The reachable Git history guard is also run
locally and by public CI. These checks cover the reviewed source and artifacts;
they do not claim to be a proof that all possible secrets can be detected.

## Installed-wheel live probes

The actual installed wheel, using isolated cache/output directories and no saved
cookies or account credentials, completed 18 cases across 13 distinct tools:
**13 PASS, 4 BLOCKED, 1 network timeout**. Resource and Prompt reads also succeeded.

Domestic search, exact C-code/MPN, stock, quantity pricing, parametric filtering,
comparison and barcode lookup passed. JLCPCB basic-library search passed;
preferred-library search returned `ACCESS_DENIED`, and extended/no-fee/category
queries returned `RATE_LIMITED`. The host cooldown was honored, with no access
control bypass. These blocked cases are not counted as successful data retrieval.

The alternatives query initially returned a structured `NETWORK_ERROR` after the
test's 10-second timeout with retries disabled. One bounded recheck with a
20-second timeout and one retry returned normally with zero candidates. This
confirms recovery and a valid empty-result response; candidate ranking was not
validated by that live recheck. Its mocked regression coverage remains separate.

Mouser, Huaqiu and DigiKey adapters are not implemented or tested in this version.
Full manual Altium GUI/Datasheet manufacturing acceptance is **NOT_RUN**. The
release remains a pre-release.
