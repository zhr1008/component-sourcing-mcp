# Component Sourcing MCP v0.8.0-rc.3

This candidate fixes selection omissions and conflicting domestic procurement
data found in actual use. `szlcsc_discover` performs bounded functional, translated
and family queries, follows upstream pages and covers different package/pin
variants. It reports query coverage, partial failures, remaining candidates and
unknown requirements. Exact lookups remain strict; an empty query is not proof
that a part is unavailable in the market.

Domestic search inspects a stable 30-row upstream page independently of its output
limit. Current own-product page data supersedes stale mobile API inventory and
MOQ. Public advertised prices without a quantity interval are reported separately;
they no longer inherit stale price ladders or become fabricated quantity quotes.
The protected full price endpoint is not bypassed. Product Datasheets are selected
from product attachments rather than generic compliance PDFs. Cached snapshots
exclude recommendation, session and tracking state.

There are 50 tools, two Resources and two Prompts. Selection instructions and the
domestic selection Prompt now require variant coverage, explicit uncertainty and
manufacturer evidence for qualifications.

See [usage-driven fixes](../audits/selection-recall-2026-10-29.md) and
[automated validation](../test-reports/v0.8.0-rc.3-automated.md). Mouser/DigiKey
authenticated live validation requires user credentials. Huaqiu's adapter contract
and optional Altium dependency advisories remain unresolved. This is a pre-release.
