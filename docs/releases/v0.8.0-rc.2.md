# Component Sourcing MCP v0.8.0-rc.2

This release candidate fixes correctness and data-integrity defects found during
a comprehensive source review. CAD rescans invalidate changed verification
evidence, retry failed parsing and respect footprint-library identity. Domestic
exact MPN lookups can use manufacturer/package filters to resolve ambiguity.
Library repairs preserve unrelated records and report shared-group changes;
unknown inventory remains unknown.

Additional fixes protect incomplete migrations, Datasheet identity/source evidence,
existing PDF validation, quantity-of-work reporting and cache refresh during library
sync. Spreadsheet-facing CSV exports escape formula-like text while JSON retains
original values. Installation scripts stop on failures and target their own project.
Publication requires successful push CI for the exact release commit.

See the [review and repair record](https://github.com/zhr1008/component-sourcing-mcp/blob/v0.8.0-rc.2/docs/audits/comprehensive-2026-10-29.md)
and [automated validation](https://github.com/zhr1008/component-sourcing-mcp/blob/v0.8.0-rc.2/docs/test-reports/v0.8.0-rc.2-automated.md).
The server retains 49 tools, two Resources and two Prompts.

Mouser/DigiKey authenticated live testing still requires each user's approved
credentials. Huaqiu remains an application/documentation channel pending a verified
adapter contract. Optional Altium upstream dependency advisories and manual
manufacturing acceptance remain open; this is a pre-release.
