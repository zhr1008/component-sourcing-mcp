# Component Sourcing MCP v0.8.0-rc.5

安装包内的 Skill 现在叫 **`$component-sourcing`**，目录为 `skills/component-sourcing/`。下载 ZIP 后复制整个目录到 Codex 的 Skill 安装位置。从旧版升级时，移除旧 `szlcsc` Skill 副本，并更新提示词里的显式调用名称。

- **用中文查料**。按需求给最多五个立创候选，附完整订购型号、关键参数、立创料号、依据和可直接粘贴到 AD 的 Comment、中文 Description。追加数量后可补查库存与报价。
- **离线核对 Altium 文件**。可选的 `altium-offline-library` 服务读取和校验 `.SchLib` / `.PcbLib`。Skill 自带脚本可查看已保存的 `.PrjPcb` / `.SchDoc` / `.PcbDoc`。这些离线入口直接读取磁盘文件，无需启动 Altium Designer。
- **兼容旧调用**。`szlcsc_*` 工具名、`szlcsc-mcp` 命令入口以及既有 Resource 和 Prompt 保持兼容。服务共提供 51 个工具、两个 Resource 和两个 Prompt。

ZIP 包含源码和 Skill。Wheel 用于安装 Python MCP 服务。离线查库服务通过上游单独安装，配置示例见离线接入指南。
