# Component Sourcing MCP v0.7.0-rc.4

First public source snapshot with a fresh history. Provides 45 tools for domestic
SZLCSC sourcing, JLCPCB assembly-library search, datasheets, EasyEDA/Altium and
managed component libraries, plus one Resource and one Prompt.

Mouser, Huaqiu and DigiKey are documented integration candidates, not working
providers in this release. The Python distribution is `component-sourcing-mcp`;
the module `szlcsc_mcp`, old CLI alias and `szlcsc_*` tool names remain compatible.

Altium parsing/writing is an explicit `[altium]` extra, requiring Python 3.12+.
The default sourcing installation excludes it because the current upstream
Altium package pins vulnerable lxml/Pillow versions. Those optional dependencies
are not declared fixed; see `docs/dependency-security.md` before enabling CAD.

Validation covers offline unit/mock tests, actual MCP transport processes,
publication safety and reachable-history privacy rules. GitHub Actions records
the exact public commit. Full manual Altium/Datasheet acceptance is NOT_RUN;
this release remains a pre-release and must not be described as manufacturing
approval. AGPL dependencies are disclosed in THIRD_PARTY_NOTICES.md.

The installed-wheel live smoke run recorded 13 passes, four upstream access/rate
restrictions and one network timeout. A bounded alternatives recheck recovered
with an empty result; it does not validate candidate availability or ranking.
See the automated validation record under `docs/test-reports/` for scope and
reproduction commands in README. Upstream restrictions are not counted as passes.
