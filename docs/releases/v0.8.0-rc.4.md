# Component Sourcing MCP v0.8.0-rc.4

新增中文需求选型工具 `szlcsc_select`。默认最多给 5 个立创候选，每项包括完整订购型号、立创料号、封装、关键参数、证据和可直接复制的 Altium Designer Comment、Description。商城缺少参数证据时列出待核实的条件。

同一轮选型可以沿用上次的条件，再修改精度、封装或数量。给出采购数量后才查询当前商品页的库存、起订量和对应数量的价格。商品页只有展示价时，数量单价和总价保持待核实。精确查料及系列补搜可切换到只查目录的模式。

技能按中文选型、补找系列、精确查料、采购报价和库文件任务给出各自的工具入口。查料、生成 AD 字段和离线库文件处理使用器件与库文件工具。

本版包含 51 个工具、2 项 Resource 和 2 项 Prompt。贸泽和 DigiKey 的授权联网需要用户自己的凭据。华秋已列出官方 API 申请渠道，适配器有待获得正式协议。Altium 文件转换依赖及验证边界见接入文档。
