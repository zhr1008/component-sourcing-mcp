# Component Sourcing MCP v0.8.0-rc.7

中文请求如「选 10K 电阻，0603，100mW，1%」现在会同时保留阻值、封装、功率和公差。筛选识别毫欧、兆欧及分数瓦。AD 候选和表格草稿提供通用描述及具体型号描述，沿用已核对字段优先的导出流程。

目录选型可以使用搜索结果已有的详情标识，减少重复查询。取得精确 C 号后结束分页，按 MPN 查询仍会检查多个渠道条目的歧义。指定优先品牌时，在匹配证据相当的候选中优先展示该品牌，其他合格品牌继续作为备选。

离线检查脚本支持从 IntLib 读取库件名、保存的参数和封装引用。需要补充已有器件包的原厂证据时，核验工具可保留先前记录。封装生成、核验仍由显式 CAD 需求触发。
